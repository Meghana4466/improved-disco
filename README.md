Retail Sales Performance & Revenue Analysis | Excel

Project Overview

This project explores 500 retail transactions recorded throughout 2024 to understand how revenue varies across regions, products, sales representatives, and months. An Excel dashboard was developed to compare performance and identify the strongest contributors to overall sales.

Key Business Findings

- Total Revenue: 2,233,937
- Total Orders: 500
- Highest Revenue Region: East (615,806)
- Best-Selling Product by Revenue: Phone (459,170)
- Top Sales Representative: Charlie (459,753)
- Highest Revenue Month: June (222,194)

Analysis Performed

- Compared revenue across four regions.
- Evaluated sales contributions from six products.
- Analyzed individual sales representative performance.
- Examined monthly revenue trends.
- Calculated total revenue, order count, and average sales value.

Tools & Techniques

- Microsoft Excel
- Excel Formulas (SUM, COUNT, AVERAGE)
- Pivot Tables
- Pivot Charts
- Data Analysis
- Dashboard Visualization

Workbook Structure

- SalesData – Raw transaction records.
- Provit T – Pivot Table summaries.
- Dashboard – Visual representation of sales performance.

Project Objective

To transform raw retail transaction data into meaningful business insights and make sales performance easier to understand through Excel reporting.
